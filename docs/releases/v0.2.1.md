# ClipFlow v0.2.1

这是一次插入到 Excel 的修正。v0.2.0 在剪贴板没有 XML Spreadsheet 时，两条插入命令只根据 HTML 判断单元格。Excel 复制一块全是文本、数字格式为常规的区域时，HTML 里只有一个 General，没有标出这些格子是文本。插入之后，像 2025-11-01 这样的文本日期会变成序列号，文本数字会变成真正的数字，较长的小数会被缩短。v0.2.1 让「插入到 Excel（下移单元格）」和「插入到 Excel（右移单元格）」改从 Excel 放在剪贴板上的工作簿包读取真实单元格类型（inline-string）。常规格式里按文本保存的格子仍是文本。混用的数字格式照原样保留。普通粘贴、表格预览、主窗口、快捷键、历史和常用片段与 v0.2.0 相同。

## 插入时读工作簿包里的单元格类型

- 「插入到 Excel（下移单元格）」和「插入到 Excel（右移单元格）」都读取这份工作簿包，并按复制时的选区裁切。包只用来判断类型，不会放回剪贴板，避免 Excel 把它贴成嵌入对象。
- 常规格式中按文本保存的格子保持文本。文本日期（例如 2025-11-01）不再变成序列号；文本数字仍是原来的文字；较长的小数不会被缩短。
- 同一块里已经是数字的格子，以及日期、时间和类似 `0.00` 的格式，仍按原格式保留，不会被改写成文本。
- 剪贴板上已有 XML Spreadsheet 时仍优先使用它。工作簿包的选区与复制内容对不上时，仍退回 HTML。普通粘贴的顺序不变：XML Spreadsheet、Biff、HTML、RTF，然后是文字。预览图、PDF 和 OLE 类型仍不写回。

## 中文

两条插入到 Excel 的命令（下移单元格、右移单元格）会从 Excel 放在剪贴板上的工作簿包读取真实单元格类型，包括 inline-string。常规格式里的文本保持文本：像 2025-11-01 这样的文本日期不再变成序列号，文本数字仍是文本，较长的小数不会被缩短。混用的数字格式照原样保留。

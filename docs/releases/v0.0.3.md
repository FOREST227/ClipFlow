# v0.0.3

## 新功能

- **隐藏 Dock 图标**：新增设置选项，开启后 ClipFlow 不再出现在 Dock 和应用切换器中，仅通过状态栏图标或快捷键访问，适合偏好纯状态栏工具的用户
- **缩略图降采样**：新增 `ClipFlowThumbnail` 模块，图片历史记录只缓存降采样后的缩略图用于界面展示（最大 320px），原始全尺寸图片仅在粘贴时从磁盘加载，显著降低内存占用

## 优化

- **搜索与筛选缓存**：引入 `invalidateDerivedCaches()` 机制，搜索文本、分类筛选等派生数据按需缓存，变更时统一失效，减少重复计算
- **时间格式化缓存**：`RelativeDateTimeFormatter` 改为 `nonisolated(unsafe)` 静态实例复用，避免每次访问 `timeLabel` 都重建格式化器；新增 `formattedTimeLabel(for:, relativeTo:)` 方法供外部调用
- **iCloud 同步改进**：优化云快照应用流程与同步边界处理
- **快捷面板与菜单栏**：细节布局调整，改善高密度信息下的可扫描性

## 文档

- **README 重写**：产品定位、核心交互流程、目标用户和功能描述全面重写，更清晰直接

## 修复

- **CI Release workflow**：修正 `shell: zsh` 为 `/bin/zsh {0}`（GitHub Actions 非内置 shell 格式要求），升级 runner 为 `macos-15` 以支持 Swift 6.0 构建

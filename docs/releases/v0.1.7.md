## 详情可以再次打开

- 从「应用程序」里打开 v0.1.6 后，双击一条历史、按空格，或用右键「查看详情」，应用会马上退出。从源码直接运行时不一定这样。文本、代码、Markdown 和图片详情都会这样退出。
- 详情里的代码高亮和 Markdown 预览要读安装包附带的脚本。v0.1.6 的安装包去找一套下载里没有的开发资源，找不到就退出。
- v0.1.7 改为读取安装包自己的脚本。详情可以再次打开；复制、粘贴、置顶和存为片段与 v0.1.6 相同。

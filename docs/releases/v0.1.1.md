# ClipFlow v0.1.1

本次主要改善快速粘贴面板和历史记录的条目点击处理。

## 本次更新

- 点击目标同时校验事件所属窗口与卡片的当前可见位置，避免滚动或重新呼出后沿用过期的首条命中结果。
- 修正旧面板残留的点击事件路由；单击仍只选中，只有同一条目的有效连续双击才会触发快速粘贴。
- 详情打开时明确禁用底层卡片，防止点击穿透；关闭详情后重新开始双击序列。
- 补充滚动裁剪、过期命中、旧窗口、前景遮罩，以及 SwiftUI 禁用 / 恢复等回归测试。

## 验证说明

已通过自动化回归和构造的过期命中场景验证。原始低概率实机异常尚未再次捕获，不保证所有触发条件均已覆盖。

## 系统与安装

最低系统版本仍为 macOS 12。发布安装包沿用 arm64、x86_64 和 universal 三种架构及 SHA-256 校验文件。

自动发布安装包尚未经过 Apple 公证，更新后可能需要重新授予辅助功能权限。历史记录与设置的保存格式不变。

# ClipFlow v0.1.9

这是一次 Excel 粘贴修复。v0.1.8 会把从 Excel 复制的单元格按表格保存，但 Excel 稍后会把剪贴板改成只有预览图，那张图又被记成一条新的图片。v0.1.9 不再记下这张图，最新的一条仍是表格。粘贴、只放回剪贴板和插入到 Excel 时写回能还原单元格的类型，文本格式的数字仍是文本，日期和时间保持原格式。主窗口、快捷键、历史和常用片段的用法与 v0.1.8 相同。

## 预览图不再单独入历史

- 从 Excel 复制单元格后，剪贴板上先是表格，过一会儿 Excel 会把它换成只有预览图。v0.1.8 把这次变化记成一条新的图片，最新的一条就不再是表格，再粘贴时贴出去的是图。
- v0.1.9 不再把 Excel、Numbers 或 WPS 随后这张只有图片的剪贴板记成新条目。历史里最新的一条仍是那张表。已经记进去的旧图片不会被删掉。

## 粘贴时写回单元格，并保住数字格式

- 粘贴、只放回剪贴板（不粘贴），以及插入到 Excel，都按这个顺序写回：XML Spreadsheet、Biff、带 `mso-number-format` 的 HTML、RTF，然后是文字。
- 预览图、PDF，以及 OLE 的嵌入和链接类型不再写回。写回这些类型时，Excel 会贴成图片或嵌入对象，而不是单元格。
- 因此设成文本格式的数字（例如 `00123`）仍按文本保留，日期和时间保持原来的格式，不会被重新解析成常规格式。
- 插入到 Excel 成功之后，还会按每个单元格重新套用数字格式。文本格先设成文本格式，再写回原来的字符串。

## 中文

Excel 复制单元格后稍后改成只有预览图时，不再另记一条图片，最新的一条仍是表格。粘贴、只放回剪贴板和插入到 Excel 时写回 XML Spreadsheet、Biff、带 `mso-number-format` 的 HTML、RTF 和文字，不写回预览图、PDF 和 OLE 嵌入或链接。文本格式的数字保持文本，日期和时间保持原格式；插入完成后按单元格重新套用数字格式。

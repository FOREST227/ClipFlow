# ClipFlow v0.1.2

本次更新重点调整快速粘贴列表的滚动与点击路径，并加入共享的抽屉式条目详情。

## 快速粘贴与选中

- 快捷列表改用原生 NSScrollView / NSTableView，由同一个列表管理滚动位置、可见行和条目 UUID，不再依赖外层 SwiftUI 懒列表的二次命中。
- 置顶、重新复制导致排序变化时，以未变化的可见条目保留滚动位置，减少卡片在指针下移动和视口跳回顶部。
- 单击仍只选中；只有同一条目的有效连续双击才会粘贴。执行前重新查询对应 UUID，删除或失效的记录不会换成第一条执行。
- 补齐详情刚开始打开、滚动条、卡片间隙、隐藏列表、前景控件与按下—拖动—释放的输入隔离。
- 未选中卡片底色减淡为接近白色的浅灰蓝，保留文本蓝、代码紫、链接靛青、图片青绿和敏感内容红的强调色。

## 抽屉式条目详情

- 历史页和快捷面板共用详情结构，从右键条目的可见位置展开，后层与前盖独立运动，正文延后出现，关闭时反向收回。
- 图片和代码详情可使用更大的阅读区域，短文本保持紧凑；保留复制、粘贴、置顶、更多信息，以及图片缩放和代码 / Markdown 渲染。
- 正文浅色区域保持纯白，底部操作抽屉加深一档以区分层次；遵循系统“减少动态效果”。
- 窗口关闭、失焦、页面切换或条目失效时取消未完成操作；敏感内容显示 / 隐藏及时更新已有列表行。

## 验证与范围

本机完整测试 148 项：146 项通过，2 项可选证据导出跳过。13 项滚动 / 原生列表专项重复 20 轮，包含 1,200 组滚动后双击和 240 组两次点击之间置顶重排的检查。原生组件截图与构建签名另行验证。

上述为自动化和受控原生窗口验证，不等同于所有物理触摸板时序均已覆盖，也不代表旧系统及 Intel 实机验收。遇到问题请附上系统版本、芯片型号和操作步骤；截图或录像请遮住私人剪贴内容。

## 系统与安装

最低目标仍为 macOS 12，提供 arm64、x86_64、universal 三种 DMG 及各自的 SHA-256 校验文件。历史记录与设置格式不变。

GitHub 自动发布安装包尚未经过 Apple 公证，更新或签名变化后可能需要重新授予辅助功能权限。

# ClipFlow v0.2.0

这是一次表格预览和详情卡片的修正。v0.1.9 已经把从 Excel 复制的单元格按表格保存，粘贴和插入到 Excel 的写法也已经定下来。详情标题却仍写着「文本」，正文把用制表符分开的单元格折成一段文字；详情底部的操作只剩按钮底色，标题被遮掉。v0.2.0 把这类记录标成「表格」，按可滚动的网格预览，并让详情操作重新显示文字，卡片颜色与历史窗口一致。粘贴、只放回剪贴板和插入到 Excel 与 v0.1.9 相同。主窗口、快捷键、历史和常用片段的用法也不变。

## 复制的表格按网格预览

- 从 Excel 等处复制的单元格，如果记录带有「表格」标记、HTML 表格，或 XML Spreadsheet，详情、历史列表和快速粘贴都会标成「表格」，不再标成「文本」。普通文字，哪怕中间有制表符或换行，仍是文本。随后那张只有预览图的记录仍是图片。
- 网格用已经保存的内容来画：多列时优先用制表符分隔的文字；纯文本被折成一列时，改用 HTML 表格补回各列；两者都没有时再用 XML Spreadsheet。这一步只用于显示，不改剪贴板。
- 详情里的网格可以上下、左右滚动。最多画出 120 行、32 列。再多的部分不逐格绘制，并写明还有多少行、多少列没有显示。
- 历史列表和快速粘贴用更紧的预览：多于一个单元格时卡片加高，只显示前 3 行、前 4 列，放不下时给出同样的提示。只有一个单元格时仍用原来的矮行，标题仍是「表格」。
- 粘贴、只放回剪贴板（不粘贴），以及插入到 Excel，仍按 v0.1.9 写回原来的单元格类型。文本格式的数字保持文本，日期和时间保持原格式。

## 详情操作按钮看得到字

- 详情底部原来先铺上按钮底色，再被遮罩裁掉文字，看起来是一排空白胶囊。v0.2.0 把每个操作画成普通文字或符号，复制、粘贴、置顶等标题重新可见。
- 详情卡片改用和历史窗口相同的玻璃、行底色和强调色。浅色模式不再是另一层偏蓝的外壳，深色模式也与主窗口一致。

## 中文

从 Excel 等处复制的表格会标成「表格」。详情里按可滚动的网格预览，最多显示 120 行、32 列；历史和快速粘贴显示更紧的前几格。普通文本仍是文本。详情操作按钮重新显示文字，卡片在浅色和深色下都与历史窗口一致。粘贴和插入到 Excel 的行为不变。

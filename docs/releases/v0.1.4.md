# ClipFlow v0.1.4

本次更新收紧剪贴记录的隐私边界，粘贴时恢复富文本和文件链接，并修正历史列表、设置页和快捷键字形。

## 隐私与记录

- 剪贴板带有 `org.nspasteboard.ConcealedType`、`TransientType` 或 `AutoGeneratedType`（含旧文档里的 `AutogeneratedType` 拼写）时不再记入历史。密码管理器复制凭据时会打上这些标记，浏览器扩展里的复制也会跳过。
- 钥匙串、系统“密码”，以及 1Password、Bitwarden、LastPass、KeePassXC、Dashlane、Enpass、Proton Pass、NordPass、Keeper、Strongbox、MacPass、RoboForm 使用同一份列表：默认不记录，并按敏感来源处理。已经保存的排除列表会保留；这些应用即使没写在列表里也不会被记录。点“恢复默认”会写回这份新列表。
- 退出时立刻写入还在等待的历史，避免退出前最后一次复制丢失。
- 敏感正文改存钥匙串。`history.json` 只保留元数据和引用，打开旧历史时会把仍以明文保存的敏感内容迁入钥匙串。同步到“文稿/ClipFlow”时不会写入仍带密钥引用的条目。
- 搜索受保护或保险库条目时，只匹配标题、来源应用和标签，不会为了搜索去读钥匙串里的正文。
- 单独的 4–8 位数字，只有旁边写着验证码一类用语，或复制来自“信息”/验证器（含最近两分钟内这类复制）时，才当作验证码。单独的 6 位数字仍视为敏感。年份、价格和其他位数的纯数字按普通文本保存。
- 置顶只记下置顶时间，不再改写复制时间。开启文稿同步后，已删除的条目不会因为曾经置顶又出现。同步按条目合并，并在同一次协调写入里完成，避免两台 Mac 用整份文件互相覆盖。
- 敏感内容到期清理改在剪贴板变化时，或至少每 30 秒进行一次，不再每次轮询都清理。

## 粘贴与权限

- 网页复制经常同时带一张预览图。只要剪贴板里有可用的文字、RTF 或 HTML，就按文本保存，不再把预览图记成图片。
- 再次粘贴或复制回剪贴板时，恢复当时的 RTF、HTML 和文件链接。更早的历史文件仍可打开；敏感条目的这些格式与正文一起放在钥匙串。
- 启动时只静默检查辅助功能，不再立刻弹出系统授权。第一次自动粘贴才请求权限；若未授权，内容留在剪贴板，并提示打开“系统设置 → 隐私与安全性 → 辅助功能”，或在目标输入框按 ⌘V。
- 代码高亮或 Markdown 的渲染脚本缺失时，详情改为纯文本，并在日志中记录，不再因此崩溃。

## 历史与详情

- 提高次要文字、状态文字和分类色的对比度。筛选标签在较窄窗口里可以横向滚动，两端淡出，不再被裁掉。
- 详情只保留一个标题。打开详情时，历史列表用遮罩变暗，不再模糊整份列表；已显示的行和滚动位置保持不动。系统要求显示滚动条时，滚动条叠在内容上，不把列表挤窄。
- 清空未置顶历史前会确认，并说明置顶条目会保留、此操作不能撤销。没有未置顶条目时，该按钮不可用。
- 历史页也可以按 ⌘1–⌘9 粘贴当前列表里对应位置的条目。每一行向 VoiceOver 提供复制、置顶和删除。

## 设置与快捷键

- 排除列表显示当前已保存的规则；规则不合法或保存失败时，错误写在列表旁边。快捷键录制结束后不再继续吃掉按键。
- 开机启动的开关会反映系统状态：已开启、需要在“系统设置 → 通用 → 登录项与扩展”中允许、设置失败，或在 macOS 12 上需到“用户与群组”里手动添加。
- 深色模式使用深色配色。带引号的路径和说明保持在同一行，不再从引号中间折断。排除列表超出高度时显示滚动条。
- 窗口红绿灯放在侧栏上方的横条里，不再压在侧栏分隔线上。
- 快捷键里的修饰键（如 ⌃）和字母分开绘制，间距 3pt，并与字母的视觉中线对齐。VoiceOver 仍朗读不带空格的快捷键字符串。

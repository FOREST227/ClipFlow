## 复制一次，不止用一次

刚复制的内容被下一次复制覆盖了？一段文字需要反复粘贴？ClipFlow 会记录剪贴历史，让你随时找回需要的内容。

- **快捷粘贴**：按 `⌥ Option + V`，在鼠标附近打开面板，双击需要的条目即可粘贴。
- **轻松查找**：搜索历史，按内容类型筛选，把常用内容置顶。
- **文本与图片都能保存**：查看图片缩略图，识别链接和代码，保留文本原有的缩进与换行。
- **菜单栏随手可用**：点击菜单栏图标查看最近内容，通过“查看全部”进入完整历史。
- **按自己的习惯设置**：自定义快捷键，选择浅色、深色或跟随系统外观。
- **控制记录范围**：随时暂停监听、排除指定应用，并自行选择是否让敏感内容自动过期。

## 下载与安装

前往 **[下载页面](https://github.com/FOREST227/ClipFlow/releases/latest)**，在附件（Assets）中选择适合你的 `.dmg` 安装包：

| 你的 Mac | 选择的安装包 |
| --- | --- |
| Apple 芯片，例如 M1、M2、M3、M4 系列 | 文件名含 `arm64` |
| Intel 处理器 | 文件名含 `x86_64` |
| 不确定，或希望两种 Mac 都能使用 | 文件名含 `universal` |

在苹果菜单 ** → 关于本机** 中可以查看芯片或处理器型号。`.sha256` 是可选的文件校验信息，日常安装只需下载 `.dmg`。

1. 打开下载的 `.dmg`，将 **ClipFlow** 拖入“应用程序”。
2. 从“应用程序”打开 ClipFlow。
3. 按提示授予“辅助功能”权限，即可使用自动粘贴。

> 当前发布包尚未经过 Apple 公证，首次打开可能被系统拦截。确认来自本仓库后，可在系统“隐私与安全性”（旧版为“安全性与隐私”）中允许打开。更新版本后，系统也可能要求重新授予辅助功能权限。

## 第一次使用

在任意应用中复制一段文字、链接或图片，然后回到需要粘贴的位置：

1. 按 **`⌥ Option + V`** 呼出快速粘贴面板。
2. 找到需要的历史条目。
3. **双击条目粘贴**，或单击选中后点击“粘贴选中项”。

菜单栏面板中，单击条目可复制；开启面板底部的“快贴”后，也能双击粘贴。想查找更早的内容，点击 **“查看全部”**。主窗口顶部可以切换“设置”和“剪贴历史”。

### 调整为你习惯的样子

| 想要调整 | 在哪里设置 |
| --- | --- |
| 更换呼出快捷键 | 设置 → 全局快捷键，点击当前组合后按下新组合 |
| 切换浅色、深色或跟随系统 | 设置 → 外观 |
| 暂停记录、设置开机启动 | 设置 → 启动与运行 |
| 排除应用、调整敏感内容过期 | 设置 → 敏感内容 / 排除应用 |
| 启用文稿目录同步 | 设置 → 文稿目录同步 |

快捷键修改会自动保存，录入时按 `Esc` 可取消；`⌘ Command + V` 保留用于粘贴。macOS 12 的开机启动需在系统“用户与群组 → 登录项”中手动添加 ClipFlow。

## 隐私，由你掌握

ClipFlow 支持识别部分敏感内容，并以遮罩形式展示。敏感记录仅保留在本地，不参与文稿目录同步；自动识别无法覆盖所有情况，处理私密信息时也可以暂停监听或排除对应应用。

**“敏感内容 5 分钟后自动删除”默认开启，也可以自行关闭。**

- 开启时，从复制时间起计算 5 分钟，置顶的敏感条目也会过期。
- 关闭时，敏感内容仍以遮罩显示、仅本地保存，但不再按此规则自动删除。
- 重新开启时，会清理已经超过 5 分钟的敏感记录。

需要长期保存的重要内容，请另存到合适的位置。

## 常见问题

### 为什么能记录，但不能自动粘贴？

自动粘贴需要“辅助功能”权限。请在系统设置的 **隐私与安全性 → 辅助功能** 中开启 ClipFlow；旧版 macOS 可在“安全性与隐私 → 隐私”中找到。

未授权时仍可记录历史，也可以在菜单栏面板中单击条目复制后，手动按 `⌘ Command + V` 粘贴。

### 启动时会打开哪个页面？

启动或再次打开 ClipFlow 时，只在菜单栏显示应用图标，不自动弹出窗口，也不显示程序坞图标。点击菜单栏图标可查看最近内容，通过“查看全部”进入历史，或点击“设置”打开设置页。

### 开启同步后，就能在其他 Mac 上看到历史吗？

文稿目录同步会把普通历史保存到 **文稿/ClipFlow**。只有系统开启 iCloud Drive 的“桌面与文稿文件夹”同步时，这个目录才会随系统同步到其他设备；其他 Mac 也需要安装 ClipFlow 并开启相应同步设置。

同步速度取决于 iCloud Drive。敏感记录不会参与同步；同步目录中的旧图片可能继续保留，不会随着本机历史删除而全部自动清理。

### 支持旧版 macOS 吗？

最低支持 macOS 12。当前已验证以 macOS 12 为目标的 Apple 芯片与 Intel 编译，macOS 12 实机运行仍需进一步验证。

# ClipFlow v0.1.3

本次更新重新整理了主窗口、快速粘贴面板和菜单栏面板的布局，并补上键盘操作与卡片上的就地操作。

## 主窗口与历史页

- 侧栏把“剪贴历史”放到最上方，“通用 / 隐私 / 同步”三项设置收到底部分组。
- 筛选区从两行六个大卡片改为一行标签：全部 / 置顶 / 文本 / 代码 / 链接 / 图片 / 敏感。原来的“快速粘贴”“智能分组”两个分类含义不直观，已由“置顶”“文本”“图片”取代。
- 历史列表随窗口高度伸缩，至少显示六行；窗口宽度可在 620–880 之间调整，最小高度 720。
- 鼠标悬停卡片时显示复制、置顶、删除按钮；双击卡片或按空格打开详情，↑ / ↓ 切换选中项。
- 右键卡片改为打开操作菜单：查看详情、粘贴、复制、置顶、显示 / 隐藏敏感内容、访问链接、删除。此前右键直接打开详情。

## 快速粘贴

- 支持全程键盘操作：↑ / ↓ 选择并滚动到可见位置，↩ 粘贴选中项，⌘1–⌘9 直接粘贴对应位置的条目，空格打开详情。前九行在卡片右上角显示对应的 ⌘ 数字。
- 输入法组字期间这些按键仍交给输入法；搜索框里已有文字时，空格按普通字符输入。
- 标题栏显示将要粘贴到的目标应用；底部由两个按钮改为一行快捷键提示和“历史记录”入口。
- 右键卡片同样打开操作菜单，搜索无结果时给出单独的提示。

## 菜单栏面板

- 顶部三个统计块精简为一行状态：监听状态、历史条数和呼出快捷键。
- 面板高度跟随内容，不再固定 440 并在底部留白。

## 其他

- 统一搜索框、列表行的圆角与高度；权限检查弹层的条目底色改用调色板颜色，深色模式下不再是白底。
- 权限检查弹层显示时，历史列表不响应键盘操作。

## 验证与范围

本机完整测试 162 项：160 项通过，0 项失败，2 项可选证据导出跳过。另在运行中的应用里逐项验证 12 项交互：悬停操作按钮、历史与快速粘贴的右键菜单、双击与空格打开详情、键盘选择与粘贴（含 ⌘1–⌘9）、输入法组字不受干扰、窗口缩放范围，以及深色模式下的筛选标签、悬停按钮、菜单栏面板和快速粘贴。验证环境为 macOS 26 / Swift 6.3.3。

上述为自动化测试与受控手动验证，不等同于所有物理触摸板时序均已覆盖，也不代表 macOS 12 及 Intel 实机验收。遇到问题请附上系统版本、芯片型号和操作步骤；截图或录像请遮住私人剪贴内容。

## 系统与安装

最低目标仍为 macOS 12，提供 arm64、x86_64、universal 三种 DMG 及各自的 SHA-256 校验文件。历史记录与设置格式不变。

GitHub 自动发布安装包尚未经过 Apple 公证，更新或签名变化后可能需要重新授予辅助功能权限。

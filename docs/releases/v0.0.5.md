# ClipFlow v0.0.5

本次发布统一窗口、外观与快捷键体验，并整合 v0.0.4 的 macOS 12 兼容和多架构打包能力。

## 界面与交互

- 剪贴历史与设置合并为一个窗口，顶部左侧“设置”、右侧“剪贴历史”；切换时保留搜索条件和未保存的排除规则草稿。
- 保留渐变标题、状态概览、分类图标、条目标签，并统一标题区与分页控件排版。
- 主窗口宽 500 点，菜单栏与快速粘贴面板宽 360 点。
- 启动选项开启时在菜单图标处展开弹窗，关闭时打开剪贴历史；不再自动恢复设置窗口。
- 支持自定义快速粘贴快捷键、冲突提示、Esc 取消及恢复默认。
- 支持浅色、深色、跟随系统；手动切换只有实际颜色变化时才执行短淡入淡出，并尊重减少动态效果设置。

## 隐私与可靠性

- 敏感内容支持复制后 5 分钟自动删除，用户可关闭；开启时置顶不豁免，空闲或暂停监听时也会清理。
- 自动删除默认开启，已有敏感记录也按原复制时间计算。升级前需要长期保留的内容应另行保存。
- 保存并回贴原始文本，避免丢失缩进或末尾换行。
- 历史文件读取失败时保留原文件和图片，防止误删可恢复资源。
- 历史达到容量上限时优先保留置顶内容。
- 修复暂停恢复后漏记下一次复制、取消同步任务反而立即同步的问题。
- 同步文件操作移至后台，避免旧快照覆盖同步期间的本地修改；未变化的历史不再周期性重写。
- 图片列表使用降采样缩略图及缓存预算，原图保留用于粘贴。
- 不根据单台设备的历史快照清理同步目录图片，避免误删其他设备尚未同步完的文件。

## 兼容与发布

- 最低运行系统 macOS 12；提供 Apple Silicon、Intel 和 Universal 三种 DMG 及 SHA-256 校验文件。
- macOS 12 使用兼容布局与 API 回退；开机启动需手动加入系统登录项。
- 读取兼容 v0.0.4 的外观偏好和快速粘贴快捷键配置。
- 当前界面以本次确认版本为准；旧版菜单栏／历史／设置的独立自定义快捷键及隐藏 Dock 入口未沿用，统一通过菜单与页面切换访问。
- 本地源码构建支持固定自签名身份，构建时不自动重建证书、不静默退回临时签名。
- GitHub Actions 发布包使用明确的 ad-hoc 签名，不包含个人私钥，也不是 Apple 公证发行包。其权限连续性不同于本机固定签名构建。

兼容性验证包括 macOS 12 部署目标下的双架构编译；macOS 12 实机运行仍需进一步验证。

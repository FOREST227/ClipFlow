# ClipFlow v0.3.0

本次更新带来全新的 **「陶纸活页叠卡盒（Archival Filing Box）」** 界面体系、**扇形流转快速粘贴面板**、**顺序粘贴队列**、**硬件 VSync 级全链路动画优化**，以及全新的 **温润浅陶叠卡匣应用图标**。

## 核心更新

- **陶纸活页叠卡盒与右侧时间刻度尺**：
  - 主窗口新增默认「叠卡」视图（可随时与「清单」模式切换），按从上到下时间顺序展示最新卡片与前后叠层。
  - 鼠标悬停队列卡片可在原槽位内抽出半截直接预览文本/代码或图片内容；按空格或点击展开按钮可平滑抽出完整详情卡片。
  - 右侧时间刻度尺支持点击滑行与 120Hz 拖拽定位，滚动或悬停绿点时自动浮现当前卡片序号，静止后自动隐藏。
- **书口分类折签与暗色模式高对比度调校**：
  - 左侧活页书口分类折签（`全部 / 置顶 / 文本 / 代码 / 链接 / 图片 / 敏感`）适配温润宣纸浅色与静谧矿物暗色双主题，选中态带清晰色标竖条并与页面无缝衔接；窗口支持贴边停靠（Edge Peek）。
- **扇形快速粘贴（`⌥V`）与顺序粘贴队列**：
  - 快速粘贴升级为无边框 5 卡扇形流转面板，支持触控板连续滑行、滚轮步进、空格查看详情及直接粘贴。
  - 新增「顺序粘贴」队列（FIFO 依次弹出粘贴 + 可选复制自动加入），批量搬运多条内容更顺手。
- **零延迟代码 / Markdown / 表格预渲染与 VSync 流畅度优化**：
  - 复制入库与启动时在后台预渲染代码语法高亮、Markdown 排版与表格视图，快速滑卡与打开详情零闪烁、零白屏等待。
  - 叠卡弹簧与卡片抽出动画全面改用 `CVDisplayLink` 硬件 VSync 驱动，修复顶/底边界滚动抖动及超宽图片卡片布局溢出。
- **清单模式与详情页细节打磨 + 全新应用图标**：
  - 优化清单模式选中光标条对称留白、紧凑悬浮快捷操作栏与图片行排版；详情弹窗避让窗口左上角红绿灯按钮并屏蔽底层提示穿透。
  - 换装全新 macOS 液态玻璃质感「温润浅陶叠卡匣」应用图标。

## 系统与安装

- 最低支持 **macOS 12**，提供 `arm64`（Apple 芯片）、`x86_64`（Intel）与 `universal`（通用）三种 `.dmg` 安装包及对应 `.sha256` 校验文件。
- 版本号：`0.3.0`（Build `33`）。

# ClipFlow v0.1.8

这是一次剪贴板修复。从 Excel、Numbers 或 WPS 复制单元格时，剪贴板上除了表格文字，还有一张预览图。v0.1.7 常把这次复制记成图片，粘回去就只剩图片。v0.1.8 会保留原来的全部剪贴板类型，再粘贴成带格式的单元格。主窗口、快捷键、历史和常用片段的用法与 v0.1.7 相同。

## 表格会按单元格粘回去

- 从 Excel、Numbers 或 WPS 复制单元格时，一次复制里通常同时有制表符分隔的文字、HTML 表格、RTF，以及各应用自己的表格数据，有时还有 PDF 和一张选区预览图。
- v0.1.7 会先看到这张预览图，把记录存成图片，再粘贴时只写回图片。纯文本目标和 Excel 收到的都是图，Excel 自己的「插入复制的单元格」也看不到原来的单元格数据。
- v0.1.8 在有表格文字时按文本保存，并按原来的类型和顺序写回全部数据。粘贴到 Excel、Numbers 或 WPS 时仍是带格式的单元格；粘贴到纯文本目标时是制表符分隔的文字。列表和详情显示文字，不显示那张预览图。
- 更早的历史文件仍可打开。没有这些额外类型的旧记录，粘贴方式与 v0.1.7 相同。

## 只放回剪贴板

- 保留了原始剪贴板类型的记录，右键菜单和详情里增加「只放回剪贴板（不粘贴）」。它把当时的全部类型放回系统剪贴板，不发送 ⌘V。
- 放回之后，可以在 Excel 里自己用选择性粘贴，或「插入复制的单元格」。
- 若复制之后工作簿已关闭，或 Excel 已经退出，Excel 可能仍认为这次复制不属于当前会话，「插入复制的单元格」会保持不可用。这时改用「插入到 Excel」。

## 插入到 Excel

- Excel 正在前台，或它是你刚才离开的应用时，表格记录还会提供「插入到 Excel（下移单元格）」和「插入到 Excel（右移单元格）」。
- 这两项按当前表格的行数和列数，在活动单元格处插入一块同样大小的区域，把原有单元格下移或右移，然后粘贴原来的格式。
- 这需要允许 ClipFlow 控制 Microsoft Excel。系统会在「隐私与安全性 → 自动化」里询问。未允许，或 Excel 没有在运行，或当前工作表无法插入时，改为普通粘贴，并在状态里说明。

## 中文

从 Excel、Numbers 或 WPS 复制的单元格会保留剪贴板上原来的全部类型，粘贴回去仍是带格式的单元格，而不是预览图。可以「只放回剪贴板（不粘贴）」，自己再用选择性粘贴或「插入复制的单元格」。Excel 在前台或刚用过时，还可以插入并下移或右移单元格；这需要自动化权限，未允许时改为普通粘贴。

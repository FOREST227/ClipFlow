# ClipFlow v0.2.2

这是一次详情卡片操作栏的调整。v0.2.1 把粘贴、复制、置顶、存为片段、删除，以及纯文本、链接、访达和插入到 Excel 等操作都排在卡片底部。按钮一多就会折行，并伸出卡片。v0.2.2 让条目详情卡片上只保留「粘贴」（主操作）、「复制」和「…」。敏感内容另外保留「显示」；已经显示时，这个按钮写成「隐藏」。这一行因此能排进同一行，并且留在卡片里面。粘贴为纯文本、复制为纯文本、置顶、存为片段和删除收进「…」菜单。删除是红色，放在最后。菜单在卡片内部打开，用和卡片一致的浅色，不再是一块灰色的系统菜单。普通粘贴、表格预览、插入到 Excel 的写法、主窗口、快捷键、历史和常用片段与 v0.2.1 相同。

## 详情操作收进一行

- 卡片正面只显示「粘贴」（主操作）、「复制」和「…」。受保护的敏感内容在「复制」和「…」之间还有「显示」；已经显示时写成「隐藏」。
- 「粘贴为纯文本」和「复制为纯文本」只在内容带有富文本或 HTML 时出现，并收进「…」。「粘贴为纯文本」仍标着原来的 ⇧↩。置顶（已置顶时为「取消置顶」）和「存为片段」也在这个菜单里。
- 「删除条目」用红色，放在菜单最后一项，上面有一条分隔线。
- 有链接时仍可「访问链接」，有本地文件时仍可「在访达中显示」。表格记录的只放回剪贴板，以及「插入到 Excel（下移单元格）」和「插入到 Excel（右移单元格）」，也留在这个菜单里，行为与 v0.2.1 相同。
- 「…」在卡片内部打开。菜单用和详情卡片一致的浅色，不再弹出一块灰色的系统菜单，并尽量留在卡片边距之内。

## 中文

详情卡片现在只把「粘贴」、「复制」和「…」放在正面；敏感内容另外保留「显示」。粘贴为纯文本、复制为纯文本、置顶、存为片段，以及红色的「删除条目」（放在最后）都收进「…」。这个菜单在卡片内部打开，样式与卡片的浅色一致。操作仍排成一行，不再伸出卡片。

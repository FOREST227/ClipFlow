# ClipFlow v0.3.1

完整融合 `v0.3.0` 陶纸活页叠卡盒架构与 `v0.2.2` 生产力增强特性，采用全新温润浅陶叠卡匣（Ceramic Archival Card Box）应用图标。

## 本次合入亮点

### 1. 陶纸活页叠卡盒与 120Hz 原生动效（Folio Archival Card Deck）
- **温润浅陶叠卡匣图标**：贴合 Claude 陶纸暖麻与青瓷绿语义点缀，采用 macOS 原生连续曲率陶瓷浅凹内腔与三层阶梯档案纸卡设计。
- **活页叠卡（Deck）与清单（List）双模式**：顶栏一键切换；支持纵向 3D 阶梯叠卡、物理槽位悬停抽卡预览、右侧时间刻度盘（Time Dial）无级拨动与实时顺位气泡。
- **VSync 120Hz 连续丝滑动效**：基于 `CVDisplayLink` 驱动卡片滚轮物理弹簧与抽卡展开动画，消除首尾边界抖动；内置 `DetailTextPrewarmer` 预热代码高亮与 Markdown 排版，详情秒开零白闪。
- **扇形轮播快捷粘贴（`⌥V`）与顺序粘贴栈（Paste Stack）**：支持 5 卡扇形悬浮轮播与传统清单 / 常用片段一键互切，顶部提供顺序出栈快捷胶囊。

### 2. 表格网格、Excel 插入、纯文本粘贴与常用片段（完整保留自 v0.2.2）
- **电子表格网格预览与 Excel 插入**：从 Excel、Numbers、WPS 复制的单元格保留原始剪贴板类型并渲染为表格网格，支持向下 / 向右移动单元格直接插入回 Excel。
- **粘贴 / 复制为纯文本（`⇧↩`）**：带富文本或 HTML 的记录可一键剥离样式仅粘贴或复制纯文本。
- **常用片段（Snippets）**：活页书口新增「片段」折签，独立保存地址、签名、回复与代码模板，不随历史上限或敏感过期被清理，并支持文稿目录同步。
- **可配置历史保留条数**：在「设置 → 通用」支持 `80 / 200 / 500 / 1000` 条未置顶上限，调低前提供删除条数确认提示。

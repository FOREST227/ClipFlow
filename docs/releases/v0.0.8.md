# ClipFlow v0.0.8

本次更新重新整理了设置、历史记录和快速粘贴的界面，并改进条目交互、窗口响应和内容预览。

## 界面与操作

- 设置与剪贴历史整合到同一个侧栏窗口，统一浅色、深色外观与卡片层次。
- 菜单栏改为状态概览与常用开关；重启、退出集中在电源菜单。
- 历史与快速粘贴采用六单位可视区域：文本、链接占一单位，图片、代码占两单位。
- 单击条目仅选中，快速粘贴面板双击同一条目才粘贴；修正跨条目连续点击误触发。
- 调整选中竖线的内边距与长度，选中样式采用对应内容类型的强调色。
- 优化快捷面板阴影、详情背景遮罩范围与关闭过渡。

## 内容预览

- 两个入口复用精简的条目详情：来源、时间与标签合并展示，更多信息可折叠。
- 图片详情支持滚轮缩放、双指捏合、拖动查看局部和双击恢复；竖向长图获得更大的预览区域。
- 新增离线代码语法高亮、自动语言识别和手动语言选择。
- Markdown 提供源码 / 预览切换，支持标题、列表、表格、引用及代码块。
- 改进 PowerShell、macOS 命令与常见代码片段识别，减少普通英文被误判为 SQL 的情况。

## 性能与稳定性

- 选中高亮独立绘制，避免反复重建图片与文字内容。
- 按需加载设置或历史页面，历史只构建可见卡片，减少呼出延迟。
- 保留浏览位置与设置草稿，修正滚动后点击条目跳回顶部的问题。
- 快速粘贴使用激活窗口，改善触摸板捏合事件接收；保留原外部应用作为粘贴目标。
- 文稿目录同步区分启用开关与同步状态。

## 安装说明

提供 arm64、x86_64 和 universal 三种 DMG，以及各自的 SHA-256 校验文件。最低系统版本为 macOS 12。

发布包未经过 Apple 公证；首次打开或更新后可能需要系统允许打开及重新授予辅助功能权限。macOS 12 与 Intel 实机运行仍需更多验证。

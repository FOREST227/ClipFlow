# ClipFlow v0.1.5

本次更新可以把带格式的记录按纯文本粘贴，把常用文字存成不会被历史清掉的片段，并自己选择历史保留条数。

## 粘贴为纯文本

- 带有 RTF 或 HTML 的历史，可以只粘贴或只复制当时的纯文本，缩进和换行保持原样。普通粘贴仍会恢复富文本、HTML 和文件链接。
- 快速粘贴面板用 ⇧↩，或按住 Shift 双击，把选中条目按纯文本粘贴。面板底部提示为「粘贴为纯文本」。
- 历史页和快速粘贴的右键菜单，以及详情里的操作，在条目带有 RTF 或 HTML 时提供「粘贴为纯文本」和「复制为纯文本」。已经是纯文本的记录、只有文件链接的复制，以及图片，不提供这两项。
- 未授予辅助功能时，纯文本会留在剪贴板，并沿用原来的辅助功能说明。敏感条目在界面上仍遮罩；粘贴时使用的仍是真实正文，与普通粘贴相同。

## 常用片段

- 地址、签名、常用回复和代码模板可以单独保存，不进入剪贴历史。历史条数上限和敏感内容过期都不会删除它们。
- 主窗口侧栏增加「片段」。可以搜索、新建、编辑、调整顺序；删除前会确认。
- 历史行的右键菜单和详情里可以「存为片段」。
- 快速粘贴面板用「历史 / 片段」切换。片段带有「片段」标记。↑ ↓ 选择，↩ 粘贴，⇧↩ 只粘贴正文，⌘1–⌘9 直接粘贴，⌃←→ 切换范围。
- 已标记为敏感的历史必须先确认，才会以明文存成片段，并标为仅本机。
- 开启文稿同步后，普通片段写入「文稿/ClipFlow/snippets.json」，沿用同一套协调读写和墓碑合并，不受历史条数上限约束。从敏感记录保存的片段不会进入这个文件。片段文件写入失败不会关掉历史同步。

## 历史保留条数

- 「设置 → 通用」增加「历史保留条数」，可选 80（默认，与此前相同）、200、500、1000。选项和其他设置一起保存在本机。还没有保存过这项时，按 80 条。
- 置顶内容不计入这条上限，也不会为了满足上限被删掉。常用片段在历史之外，同样不受这条上限影响。
- 调高条数不会删除任何记录。调低时，若有未置顶记录会被删掉，会先说明将删除最早的多少条，点「删除这些记录」后才执行。取消则保持原来的条数。
- 确认后立刻裁剪：`history.json` 去掉这些记录，对应图片文件删除，钥匙串里的敏感正文一并清除。可同步的记录会写下墓碑，避免之后的文稿同步又把它们找回来。敏感记录只留在本机，不写墓碑。

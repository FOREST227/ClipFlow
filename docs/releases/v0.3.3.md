# ClipFlow v0.3.3

将应用内全部开关控件的开启强调色统一为 ClipFlow 主题的**青瓷绿（Celadon Sage）**，消除偏好设置与菜单栏面板中残留的 macOS 系统默认蓝，令浅色陶纸与深色暖墨主题下的控件视觉语言更加一致。

## 本次更新

- **全新主题青瓷绿开关样式（`FolioSwitchToggleStyle`）**：
  - 浅色模式开启态采用与「保存规则」「快速粘贴」主按钮一致的青瓷绿 `#386B56`，关闭态采用暖陶石底色 `#DAD6CE`。
  - 深色模式开启态采用提亮青瓷绿 `#47836D`，在深色卡片与白色滑块间保持清晰可读对比度。
  - 采用同心正圆端帽胶囊造型，支持悬停高亮、按压滑块微拉伸与平滑过渡动效，并尊重系统「减弱动态效果」设置。
- **全量覆盖偏好设置与菜单栏开关**：统一更新偏好设置（通用 / 隐私 / 同步）、菜单栏弹窗（顺序粘贴与状态开关）及设置卡片中的全部开关控件。
- **文档截图与测试更新**：刷新 `README.md` 菜单栏与偏好设置演示截图，并补充开关主题色与尺寸单元测试 `testFolioSwitchUsesThemeCeladonGreenAndCompactTrackSize`。

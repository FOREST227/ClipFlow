# ClipFlow v0.3.2

更新 macOS 顶部菜单栏状态图标，使系统状态栏、菜单栏面板与应用程序图标形成完全统一的**陶纸叠卡匣（Archival Card Box）**视觉家族。

## 本次更新

- **全新叠卡匣菜单栏模板图标**：将 macOS 状态栏图标重绘为 `18×18pt` 原生单色模板图形（双层阶梯纸卡 + 拇指凹槽卡袋），自动适配浅色与深色菜单栏；暂停剪贴监听时右下角显示清晰镂空双竖线暂停徽标。
- **同步矢量图标源文件**：更新 `assets/icon/ClipFlow-status-active.svg` 与 `assets/icon/ClipFlow-status-paused.svg`。
- **文档与测试完善**：完善 `README.md` 与 `v0.3.2` 发布说明，并新增菜单栏模板图标单元测试 `testStatusBarIconRendersArchivalCardBoxTemplate`。

## 下载与校验

- Apple 芯片：`ClipFlow-v0.3.2-arm64.dmg`
- Intel 处理器：`ClipFlow-v0.3.2-x86_64.dmg`
- 通用安装包：`ClipFlow-v0.3.2-universal.dmg`

# ClipFlow v0.1.0

在 v0.0.8 的基础上，统一详情内容区的浅色外观，并完善仓库中的功能展示。

## 本次更新

- 更新安装包，包含最新的快捷面板选中处理：高亮独立绘制，减少选中时的列表重建。
- 补充下滚后的单击、双击目标及图片 / 代码 / 文本混排回归测试。

- 浅色模式下，文本、代码和 Markdown 详情的内容区统一为纯白底色；深色模式保持深色背景。
- README 使用真实应用组件与演示数据重新配图：菜单栏边界更清晰，快速粘贴与菜单栏配图居中并排。
- 代码与 Markdown 详情展示采用窄高比例、等高卡片与轻阴影，外围背景统一纯白。
- 同步更新版本信息、下载文件名和构建文档。

## 已包含的主要功能

- 本地剪贴历史、搜索、分类筛选与常用条目置顶。
- 快速粘贴面板：单击选中，双击同一条目粘贴，右键查看详情。
- 多语言离线代码高亮，以及 Markdown 源码 / 预览切换。
- 图片滚轮和触摸板捏合缩放、拖动查看、双击恢复。
- 敏感内容遮罩、可选的 5 分钟自动过期、排除应用与文稿目录同步。
- 浅色、深色、跟随系统外观，以及自定义呼出快捷键。

## 下载与安装

提供 arm64、x86_64 和 universal 三种 DMG，以及各自的 SHA-256 校验文件。最低系统版本为 macOS 12。

发布包尚未经过 Apple 公证。首次打开或更新后可能需要在系统中允许打开、重新授予辅助功能权限。macOS 12 与 Intel 实机运行仍需更多验证。

本次 v0.1.0 安装包包含快捷面板选中层调整及其回归测试；发布标签已对齐此次构建所用提交。

自动测试和已测实机路径未再出现误选首条，但尚未确认所有触发条件均已覆盖。

# ClipFlow v0.1.6

本次更新把快速粘贴的底部提示收成一行，统一菜单和设置里的开关名称，并让 ⌘F 直接进入历史搜索。

## 快速粘贴面板

- 底部只留一行：↑↓ 选择、↩ 粘贴、⇧↩ 粘贴为纯文本，以及「历史记录」。把鼠标移到这一行，会看到 ⌘1–9 直接粘贴；历史范围还有「空格 详情」，片段范围则是「⌃←→ 切换」。VoiceOver 仍能听到这些补充说明。
- 右上角的「关闭」文字改成圆形 ✕，辅助功能名称仍是「关闭」。按 Esc 仍会关闭面板；若详情开着，Esc 先关掉详情。
- 面板少了原来单独那一行提示的高度。列表能看到的区域没有变短。复制、粘贴、纯文本粘贴和历史记录的用法与 v0.1.5 相同。

## 界面

- 菜单栏和设置使用同一组名称，开关打开表示这项功能正在工作：「记录剪贴板」「自动保护疑似敏感内容」「5 分钟后删除敏感内容」「同步普通历史」。「记录剪贴板」在菜单栏和「设置 → 通用」里都是正向开关：打开才会记下新内容，已有历史仍可使用。
- 图片卡片只到说明行加 72pt 缩略图那么高。代码卡片仍留出五行预览。快速粘贴里的图片同样变矮；横向图片在缩略图下保留一行尺寸。
- 常用片段的每一行改用历史卡片：圆角底色、强调色描边和左侧色条。分类还在，不再在每一行重复「片段」。拖动调整顺序不变。
- Markdown 的「源码 / 预览」改用和设置相同的胶囊分段控件。
- 图片详情不再在预览上重复「宽 × 高」。图片按可用高度铺满；向外捏合仍能看到整张图，双击恢复完整显示。尺寸仍写在标题里。
- 筛选标签里条数为 0 的不显示。「全部」始终在；正在查看的那一个即使是 0 也留着，空列表仍然看得出当前筛选。

## 搜索

- 菜单「编辑 → 查找」的快捷键是 ⌘F。它会把剪贴历史窗口带到前面，并把光标放进搜索框。
- 打开剪贴历史时，搜索框同样获得焦点。
- 方向键和回车仍操作列表。搜索框为空时，空格仍打开详情。输入法还有未上屏的文字时，这些键留给输入法。
- 搜索框里按 Esc，先清掉已经输入的词；再按一次，才关闭详情。
